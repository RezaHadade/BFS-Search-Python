# BFS-Search-Python
This is my implementation of the Breadth-first search(BFS) algorithm in Python.

A simple implementation of the Breadth-First Search (BFS) algorithm in Python.

# About
This project is part of my process of learning Artificial Intelligence and search algorithms.
The implementation starts with a simple graph and uses BFS to find a path from an initial state to a goal state.

# Concepts
This implementation explores some of the core concepts behind search algorithms:

* Nodes and states
* Frontier
* FIFO queue
* Graph expansion
* Goal test
* Explored set
* Path reconstruction

# Current Status
This project is a work in progress. The implementation is being developed step by step while learning the underlying concepts and improving the code structure.
